# Unlock Pool

> Thin, Slay-the-Spire-style persistence. Clearing runs unlocks new content — cards, relics, goods, gate types — into the pool for future runs. The "one more run" hook that replaces the hub.

## How it works

Progress between runs is a growing pool of content, not a production engine. Depth reached and runs completed unlock new [[systems/Action Deck|cards]], relics, good types, and gate variants, which fold into future runs' offerings — StS-style, largely automatic. This supplies the compulsion loop (variety accumulates) without a second game to build or balance.

**Optional home-base skin (deferred).** The merchant-empire flavour can return later as a purely cosmetic base that visibly fills in as you unlock — a Hades-style house, no simulation, no idle. Zero mechanical risk; layered only if wanted. See [[decisions/Drop incremental hub for thin unlock pool]].
