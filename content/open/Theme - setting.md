> What is the world, the aesthetic, and the merchant's context?

## Options on the table

The design doc uses generic fantasy/crafting placeholders throughout (ore, smithing, towns, lumber, etc.) and explicitly defers theme:

> *"Theme TBD — described here in generic fantasy/crafting terms, but every 'ore/smithing/town' is a placeholder for whatever theme we land on later."*

Possible directions (not from the doc — flagged as illustration only, not decisions):
- Classic fantasy trade route
- Sci-fi hauling / space merchant
- Historical silk road / spice trade
- Cozy / whimsical merchant
- *(Do not treat any of these as a decision — they are examples of the space, nothing more.)*

## Notes

Theme is **deliberately deferred.** The systems are designed to be theme-agnostic so the core can be validated without a theme commitment. The prototype builds a grey-box run with no art or theme (see [[meta/Prototype Scope]]).

Theme should be chosen after the core is proven, so it can complement a run that's already fun — not compensate for one that isn't.
