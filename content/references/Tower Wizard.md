# Tower Wizard

> An incremental idle game with a strong feedback-juice loop. Reference for the hub's "incremental feedback juice" feel.

## What we borrow

- **Incremental feedback juice:** the satisfying tick-tick-tick of an engine running, the visual and audio feedback of production happening. The hub should feel like this — a system you can set down and pick back up, with satisfying visible progress.
- **Watch-it-run calm:** Tower Wizard's idle phase is calm and rewarding to watch. The hub's idle state should have this quality — harmless (see [[decisions/Harmless idle, no punishment]]) and pleasant to observe.

## What we deliberately DON'T take

- **Idle as primary activity:** Tower Wizard is primarily a watching game. Our hub is a quick pit stop between runs — see [[decisions/Hub is a quick pit stop]].
- **Upgrade complexity:** Tower Wizard's upgrade trees can be deep. We want the hub visit to be quick; upgrade decisions should be fast reads, not sessions in themselves.
