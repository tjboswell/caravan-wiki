# Gnorp Apologue

> A micro incremental where swarms of gnorps mine and haul resources. The reference for "watch it scale" juice and the hub's visual feel.

## What we borrow

- **Swarm juice:** lots of individually simulated cheap things drawn without restraint — flowing cargo, converting goods, piling materials. This is the juice surface design principle for the hub (and cargo animations in the run).
- **Watch-it-scale satisfaction:** the pleasure of watching your production system run faster and faster as you upgrade it. The hub's hunger loop is designed to deliver this feeling — see [[decisions/Engine gets hungrier as it scales]].
- **Controlling a character vs. watching:** Gnorp makes explicit the tension between active play and idle watching. We use the same distinction: the run is active, the hub is the "watch it run" phase.

## What we deliberately DON'T take

- **Pure idle / no active game:** Gnorp is almost entirely a watched experience. Our active game (the run) is the main event; the hub watching is the reward between runs.
- **Resource as only loop:** Gnorp's loop is entirely resource accumulation. We have the run's skill game as the primary loop.
