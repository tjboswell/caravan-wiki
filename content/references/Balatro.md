# Balatro

> A poker-based deckbuilder roguelite. The gold standard for a run that's fun naked — combinatorial depth with a one-glance identity.

## What we borrow

- **Fun-naked core:** Balatro is fun before you understand its meta. The run works on pure "make this hand better" satisfaction. This is the standard our run must meet — see [[decisions/Run must be fun naked]].
- **Combinatorial depth from simple rules:** a small set of mechanics (poker hands + jokers) generates enormous variety and expression. Aim for the same with cargo conversions + merchant cards.
- **One-glance identity:** you understand what you're doing in Balatro within 30 seconds. Our run should be the same.
- **"It's going exponential" grin:** the feel target — see [[meta/Feel Target]].

## What we deliberately DON'T take

- **Deckbuilding meta:** Balatro's run is built from a deck of cards that you draft. Our run uses a fixed caravan of goods traded through conversion cards.
- **Luck-dominant outcomes:** Balatro's RNG can feel punishing on bad draws. We want decisions always downstream of randomness — luck deals you a situation, skill determines the outcome.
- **Ante/blind structure:** Balatro's escalating antes set the pacing. Our pacing comes from towns + actions.
