# Run must be fun naked

> The run must be fun with no hub attached — like Balatro is fun with no meta layer.

## Reasoning

If the run is only fun because the hub rewards it, the core is hollow. The prototype's single question is: "Is trading cargo up through a route of towns fun for ~15 minutes, naked, with nothing else attached?" If yes, everything else slots on top of a proven core. If no, fix the core now, while it's cheap.

This decision is the design test everything else flows from. See [[meta/Prototype Scope]].

## Rejected

- **Run as means-to-hub-end** — makes the run feel like a chore that earns hub time; not the design intent.
- **Hub-gated fun** — if you need the hub to make the run feel rewarding, the run isn't designed correctly.

## Affects

- [[systems/The Run]] — must stand alone as a compelling toy
