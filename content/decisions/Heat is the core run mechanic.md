# Heat is the core run mechanic

> The run is: load **heat** onto a grid of goods, then **Sell** to cash the heated goods for points. Everything else is setup for that release.

## Reasoning

The old run was a Century: Spice Road–style convert-goods-up-toward-contracts engine. It was fine but the designer wasn't feeling it. The Heat engine keeps the same skeleton (build an engine, chase a payout, read the situation) but with a sharper release loop borrowed from a separate brainstorm: a stored, inert substance you **stack** (cheap/big/area appliers), **multiply** (the exponential break), and **spread** (contagion across the board), then **cash in** with a gated trigger. It converts "a slow build" into "everything detonates huge" — the Balatro exponential grin, made literal. Validated fun in a grey-box prototype before locking.

## Rejected

- **Century convert-up cargo engine** — the prior core; playable but flat for the designer.
- **Cargo-value-at-end scoring** — replaced by mid-run cashing via [[systems/Selling]].
- **Positional lanes** — dropped; spread works on a static grid without movement.
