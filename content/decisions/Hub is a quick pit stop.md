# Hub is a quick pit stop

> ⚠️ **SUPERSEDED 2026-07-01** — No hub. See [[decisions/Drop incremental hub for thin unlock pool]].

> You pop into the hub between runs, spend and upgrade, and leave — it is not the main event.

## Reasoning

The hub's job is *memory and consequence* — it makes runs accumulate into something permanent — not to justify the run or demand equal attention. Keeping it a quick pit stop preserves the run as the primary activity and allows the hub to be the "calm" between high-stakes expeditions.

## Rejected

- **Hub as deep management sim** — would compete with the run for primary activity; splits the game's identity.
- **Equal time split** — the run is the main event; the hub is the consequence layer. Equal time would dilute both.

## Affects

- [[systems/The Hub]] — designed to be a quick, satisfying visit, not a second full game
